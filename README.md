# Тетрадь слов

Карточки для английских слов: курсы, занятие на сегодня, тест, диктант, пропуск, пазл, статистика.

## Файлы
- `index.html`, `app.css`, `app.js` — сам сайт.
- `courses.json` — список курсов (название, файл со словами, ссылки на словари).
- `words.json` — слова курса «Школа».
- `words/kids.json` — курс «Малыши»: алфавит (A–Z), числа 0–20 и десятки, цвета, животные, семья.
- `words/grade-10.json` — слова курса «10 класс» (сейчас примеры).
- `templates/pronouns.txt` — заготовка: местоимения + предложения, вставить через вкладку «Слова».

## Как добавлять слова
1. Открыть `index.html` в PhpStorm → значок браузера (адрес `localhost`). Вкладка «Слова» видна только там.
2. Выбрать курс, вставить слова, «Добавить», затем «Сохранить».
   В первый раз Chrome/Edge спросит папку — выбрать папку проекта (где `index.html`).
3. Commit и push. Через 1–2 минуты у детей обновится.

## Формат строк
    apple — яблоко
    [She/Her/He] is my sister. — Она моя сестра.     ← пропуск, первый вариант правильный
    This is my bag. — Это моя сумка.                 ← пазл
    # Unit 4 · Food                                   ← сменить тему для строк ниже
    [He/Him/His] is {tall|funny}. — Он {высокий|смешной}.   ← варианты: каждый раз разные

## Против заучивания
- Варианты `{a|b|c}`: в английском и в переводе группы идут по порядку, номер варианта общий.
  Если в переводе групп больше, лишние берут номер последней английской.
- Слова, которые были на двух последних занятиях, уходят в конец очереди.
- Вид упражнения для слова каждый раз другой (карточка → тест → пары → диктант…).
- Слово показывается в предложении из той же темы: EN→RU — выделено, RU→EN — пропуск.
- Ошибку переспросят через 3 задания, но в другом виде (обратный тест, пазл вместо пропуска).
- В пазле нет подсказки заглавной буквой и точкой. Слова можно перетаскивать, курсор ставится между словами.

## Курс для маленьких
В `courses.json` у курса `"level":"kids"`: без диктанта, пазлы до 6 слов, упражнения «Пары», «Сколько?».
Буква: `{"en":"A","ru":"a","kind":"letter","word":"apple","wordRu":"яблоко","pic":"🍎"}`.
Число: `{"en":"three","ru":"3 (три)","n":3}`.

Не меняйте `id` у существующих слов вручную — к ним привязана статистика детей.
