# Тетрадь слов

Карточки для английских слов: курсы, занятие на сегодня, тест, диктант, пропуск, пазл, статистика.

## Файлы
- `index.html`, `app.css`, `app.js` — сам сайт.
- `courses.json` — список курсов (название, файл со словами, ссылки на словари).
- `words.json` — слова курса «Школа».
- `words/grade-10.json` — слова курса «10 класс» (сейчас примеры).
- `templates/pronouns.txt` — заготовка: местоимения + предложения, вставить через вкладку «Слова».

## Как добавлять слова
1. Открыть `index.html` в PhpStorm → значок браузера (адрес `localhost`). Вкладка «Слова» видна только там.
2. Выбрать курс, вставить слова, «Добавить», затем «Сохранить».
   В первый раз Chrome/Edge спросит папку — выбрать папку проекта (где `index.html`).
3. Commit и push. Через 1–2 минуты у детей обновится.

## Формат строк
    apple — яблоко
    [She/Her/He] is my sister. — Она моя сестра.     ← пропуск, первый вариант правильный
    This is my bag. — Это моя сумка.                 ← пазл
    # Unit 4 · Food                                   ← сменить тему для строк ниже

Не меняйте `id` у существующих слов вручную — к ним привязана статистика детей.
